# 日本語レビュー感情分析ツール

日本語のレビュー文を、ポジティブ / ネガティブ / 中立に分類するツールです。
大学で自然言語処理を勉強したので、練習として作りました。

## やっていること

- Janomeで形態素解析をして、感情辞書と照らし合わせてスコアを計算します
- 感情辞書は自分で作りました（ポジティブ約60語、ネガティブ約50語）
- 「美味しくなかった」「悪くなかった」のような否定の反転に対応しています
- 「とても」「すごく」があるとスコアを強め、「少し」「ちょっと」だと弱めます
- キーフレーズとして、感情ワードと名詞のつながりを抽出します

## 使い方

```
pip install -r requirements.txt

python main.py "お好み焼きがとても美味しいです。店員さんも親切でした。"
python main.py --batch sample_reviews.csv
python app.py
```

`--batch` はラベル付きのサンプル24件で正解率を出します。今のところ24件全部合っていますが、サンプルは自分で書いたものなので、件数が少ないです。

`app.py` を起動すると http://127.0.0.1:5000 で簡単なデモページが開きます。

## ファイル

- `sentiment.py` — 辞書と判定の本体
- `main.py` — コマンドライン用（1文の分析と、CSVの一括評価）
- `app.py` / `templates/` — Flaskのデモページ
- `sample_reviews.csv` — 飲食店レビューのサンプル24件
